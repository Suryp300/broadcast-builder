# 🚀 Broadcast Builder Pro

A professional web application for converting Excel or CSV contact lists into WhatsApp Business Broadcast List CSV files.

## ✨ Features

- 📂 Upload Excel (.xlsx, .xls) & CSV files
- 📞 Automatically clean phone numbers
- ❌ Remove landline numbers (040, 020, 022, etc.)
- 🔄 Remove duplicate phone numbers
- ✅ Validate Indian mobile numbers
- 📊 Live dashboard with statistics
- 👀 Preview cleaned data
- 📥 Export WhatsApp Business Broadcast CSV
- 💯 Runs completely in the browser (No backend)
